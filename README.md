# DeepStreamer

Расширение для Chrome (Manifest V3), которое дорабатывает интерфейс сайта
[DeepSeek](https://chat.deepseek.com) — вплоть до почти полного реворка.

> Статус: ранняя стадия. Заложен каркас MV3-расширения, функции добавляются
> постепенно.

## Возможности

- Каркас MV3: content script, service worker, popup с настройками.
- Единое хранилище настроек (`chrome.storage.sync`) с синхронизацией между
  вкладками и popup «на лету».
- Переключатель включения/выключения расширения.
- Готовая точка расширения для DOM-правок SPA через `MutationObserver`.

## Установка (режим разработчика)

1. Открой `chrome://extensions/`.
2. Включи **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажми **Загрузить распакованное расширение** (Load unpacked).
4. Выбери папку с этим проектом (где лежит `manifest.json`).
5. Открой `https://chat.deepseek.com` — расширение активируется автоматически.

После изменений в коде жми «Обновить» (↻) на карточке расширения.

```
    │   ├── popup.css
    │   └── popup.js
    └── styles/
        └── content.css        # Стили, инжектируемые в страницу
```

## Как добавлять фичи

- **Визуальные правки** — CSS в `src/styles/content.css` под селектором
  `html[data-deepstreamer="ds-active"] ...`, чтобы отключались вместе с
  расширением.
- **Изменения DOM** — в функции `enhance()` в `src/content/content.js`
  (вызывается при загрузке и на перерисовках SPA).
- **Новые настройки** — добавь поле в `DEFAULT_SETTINGS` (`src/lib/settings.js`)
  и переключатель в `src/popup/`.
